# Netflix Data Analysis Dashboard

## Project Overview
This project presents an interactive Netflix Data Analysis Dashboard created using Microsoft Power BI.

## Objectives
- Analyze Netflix Movies and TV Shows.
- Explore content distribution by country.
- Analyze genres and ratings.
- Understand content trends by release year.
- Compare Movies and TV Shows.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Insights
- Total Movies and TV Shows available on Netflix.
- Country-wise content distribution.
- Popular genres and categories.
- Content trends over the years.
- Ratings distribution.
